- Fixed `slice2java` to generate a `@Deprecated` annotation based on `["deprecated"]` metadata, rather than from the
  `@deprecated` doc-comment tag. Now the `@deprecated` doc-comment tag only affects the generated doc-comment.
- Fixed deprecation warnings in the Java code generated by `slice2java` for Slice definitions that use a deprecated
  definition correctly, such as a deprecated field with a deprecated type, or a deprecated operation with a deprecated
  parameter type.
